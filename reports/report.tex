\begin{abstract}
This report presents the design rationale, implementation strategy, verification approach, and key insights gained during the development of a Java-based library for arbitrary precision arithmetic. The library enables mathematical operations on integers and floating-point numbers with theoretically unbounded precision, making it suitable for scientific and cryptographic computations requiring high accuracy.
\end{abstract}

\section{Introduction}
This project aims to implement a high-precision arithmetic library capable of operating on both integers and floating-point numbers with arbitrary digit length. It was developed with object-oriented programming principles and is compatible with both Java and Python interfaces. The motivation behind this project stems from the limitations of built-in data types in traditional programming languages which cannot natively support operations on extremely large or precise numerical values.

\section{Features and Language Extensions}
\label{sec:features}
This section outlines the major features provided by the library and presents illustrative examples for each. These enhancements effectively extend the capabilities of the Java language in terms of numeric computation.

\subsection*{Key Functionalities}
\begin{itemize}[noitemsep]
    \item Support for arbitrary-length integer arithmetic via the \texttt{AInteger} class
    \item Floating-point arithmetic with up to 1000 digits after the decimal point using \texttt{AFloat}
    \item Support for basic arithmetic operations: addition, subtraction, multiplication, and division
    \item Operator overloading through intuitive method interfaces (e.g., \texttt{add()}, \texttt{sub()}, etc.)
    \item Dual CLI support through both Java and Python scripts
    \item Modular and reusable packaging using \texttt{.jar}, with Maven integration
\end{itemize}

\subsection*{Illustrative Examples}
\textbf{Integer Addition:}
\begin{lstlisting}[language=Java]
AInteger a = new AInteger("1234");
AInteger b = new AInteger("4321");
AInteger result = a.add(b);  // Output: 5555
System.out.println(result);
\end{lstlisting}

\textbf{Floating-point Multiplication (via Python CLI):}
\begin{lstlisting}[language=bash]
$ python run.py float mul 1.5 2.5
# Output: 3.75
\end{lstlisting}
\subsection*{\textbf{\LARGE Design Decisions}}

\subsubsection*{\textbf{\large AInteger}}

The \texttt{AInteger} class provides support for arbitrary-precision integers using a list-based digit representation and handles all basic integer arithmetic operations with full control over signs and digit manipulation.

\paragraph*{\textbf{Internal Representation}}
\begin{itemize}
  \item Uses a \texttt{private List<Integer> digits} to store digits of the number in reverse order — least significant digit (LSD) at index 0.
  \item This ordering simplifies arithmetic operations like carry/borrow propagation.
  \item Maintains a \texttt{public boolean isnegative} to represent the sign explicitly.
  \item Chose \texttt{List<Integer>} over \texttt{String} for better performance and flexibility during digit manipulation.
\end{itemize}

\paragraph*{\textbf{Accessors and Mutators}}
\begin{itemize}
  \item \texttt{get\_digits()}: Returns the internal digit list for inspection or low-level manipulation.
  \item \texttt{set\_digits(List<Integer>)}: Allows safe replacement of the digit list, enabling transformations without exposing internals.
\end{itemize}

\paragraph*{\textbf{Constructors and Parsing}}
\begin{itemize}
  \item \textbf{String constructor}:
  \begin{itemize}
    \item Handles optional leading `-` to set \texttt{isnegative}.
    \item Parses the numeric characters into reversed digits.
    \item Ignores leading zeroes by trimming them after parsing.
  \end{itemize}
  \item \textbf{Copy constructor}: Deep-copies another \texttt{AInteger}, ensuring mutability safety.
  \item \textbf{Empty constructor}: Initializes the object to represent the integer zero.
  \item \textbf{Static parser}: Provides a clean interface to parse a string and obtain an \texttt{AInteger}.
\end{itemize}

\paragraph*{\textbf{Arithmetic Operations}}
\begin{itemize}
  \item All operations are implemented with full control over digit-wise calculation and sign logic.
  \item \textbf{Addition and Subtraction}:
  \begin{itemize}
    \item Handles same-sign and different-sign logic explicitly.
    \item Performs digit-wise carry and borrow tracking.
  \end{itemize}
  \item \textbf{Multiplication}:
  \begin{itemize}
    \item Uses standard long multiplication technique.
    \item Result sign is derived from operand signs.
  \end{itemize}
  \item \textbf{Division}:
  \begin{itemize}
    \item Performs long division by repeated subtraction and digit estimation.
    \item Returns integer quotient only (no remainder or decimal part).
  \end{itemize}
\end{itemize}

\paragraph*{\textbf{Formatting and Normalization}}
\begin{itemize}
  \item \texttt{I\_to\_String()}: Converts the internal digit list to a human-readable string, adding `-` prefix if negative.
  \item \texttt{removeLeadingZeroes()}: Normalizes internal representation by trimming leading zeroes to avoid redundancy.
\end{itemize}

\vspace{1em}
\subsubsection*{\textbf{\large AFloat}}

The \texttt{AFloat} class extends \texttt{AInteger} functionality to floating-point arithmetic with arbitrary precision by tracking decimal places through a \texttt{scale} parameter.

\paragraph*{\textbf{Internal Representation}}
\begin{itemize}
  \item Each \texttt{AFloat} instance includes:
  \begin{itemize}
    \item A private \texttt{AInteger value} storing all digits.
    \item An integer \texttt{scale} indicating how many digits lie after the decimal point.
  \end{itemize}
  \item Example: The float \texttt{1.23} is represented as:
  \begin{itemize}
    \item \texttt{value = 123}, \texttt{scale = 2}
  \end{itemize}
\end{itemize}

\paragraph*{\textbf{Constructors and Parsing}}
\begin{itemize}
  \item \textbf{Default constructor:} Initializes the number as \texttt{0.0} with \texttt{scale = 1}.
  \item \textbf{String constructor:}
  \begin{itemize}
    \item Parses optional negative sign and decimal point.
    \item Counts decimal digits and updates scale accordingly.
    \item Builds digit list in reverse, skipping the decimal point.
  \end{itemize}
  \item \textbf{Copy constructor:} Clones another \texttt{AFloat} instance.
  \item \textbf{Helper constructor:} Creates a float from an \texttt{AInteger} and a scale.
  \item \textbf{Parser:} Static \texttt{parse(String)} method returns a parsed \texttt{AFloat}.
\end{itemize}

\paragraph*{\textbf{Arithmetic Operations}}
\begin{itemize}
  \item \textbf{Addition \& Subtraction}
  \begin{itemize}
    \item Align scales of operands using \texttt{shift\_deci}.
    \item Perform underlying \texttt{AInteger} addition/subtraction.
    \item Return result with common scale, then normalize.
  \end{itemize}

  \item \textbf{Multiplication}
  \begin{itemize}
    \item Multiply internal \texttt{AInteger} values.
    \item Final scale is the sum of operand scales.
  \end{itemize}

  \item \textbf{Division}
  \begin{itemize}
    \item Shifts numerator and denominator for precision handling.
    \item Uses fixed decimal precision (default: 30 digits).
    \item Returns normalized \texttt{AFloat} result.
  \end{itemize}
\end{itemize}

\paragraph*{\textbf{Formatting and Normalization}}
\begin{itemize}
  \item \texttt{F\_to\_String()}:
  \begin{itemize}
    \item Assembles the output string with correct decimal positioning.
    \item Inserts leading zeros when necessary for values $< 1$.
  \end{itemize}
  \item \texttt{removeTrailingZeros()}: Trims insignificant zeroes after the decimal.
  \item \texttt{removeLeadingZeros()}: Removes leading zeros before the decimal point.
\end{itemize}

\paragraph*{\textbf{Decimal Utility Function}}
\begin{itemize}
  \item \texttt{shift\_deci(int)} multiplies the number by $10^n$ to align decimal places during operations.
\end{itemize}

\begin{verbatim}
python run.py float mul 1.5 2.5
\end{verbatim}

\begin{verbatim}
java -cp target/aarithmetic.jar MyInfArith int sub 1000 250
\end{verbatim}

\begin{verbatim}

}
\end{verbatim}

\subsection*{Building with Maven}
\begin{verbatim}
mvn clean install or mvn clean package
\end{verbatim}

\section{Limitations}
\label{sec:limitations}
Despite the library’s wide utility, it has the following limitations:

\begin{itemize}[noitemsep]
    \item \textit{The Algorithm used for multiplication is simple school book method which is of complexity O(\( n^2 \))}
    \item \textit{I thought of implementing some complex mathematical Algorithms for division and multiplication and also thought of using \( 10^8\) as base instead of base 10 but the code was becoming too complicated for me, so I couldn't apply it.}
    \item \textit{There is no stopage of printing of digits in float div until 30 digits even if the digits are repeating. Theres is round off for the last digit of the decimal (\(30^{th}\)} place).
\end{itemize}
